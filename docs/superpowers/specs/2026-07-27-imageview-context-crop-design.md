# Imageview 直接裁剪与右键菜单设计规格

## 1. 目标

本次迭代收紧主窗口工具栏，增加快速删除，并按干净室观察得到的
Picview 1.5.7 右键菜单结构组织 Imageview 已支持的命令。裁剪改为在
图片画布上直接框选，并由 `⌘K` 安全覆盖原文件。

本次不复制 Picview 的代码、图标、品牌资源或未观察到的内部实现。

## 2. 工具栏

- 从允许项目和默认项目中移除 `Pin Image`、`Pin Clipboard` 和
  `Extract Subject`。
- 增加 `Delete` 工具栏项目，使用系统废纸篓图标。
- 保留 `Crop` 工具栏项目作为进入框选模式的入口。
- Pin 功能本身不删除；`Pin Image` 只保留在右键菜单和现有主菜单中。
- `Pin Clipboard` 可继续保留在现有主菜单中，但不再占用工具栏。
- 主体提取代码保留，不提供主窗口按钮。

## 3. 删除

- `Delete` 工具栏按钮、主菜单命令、右键菜单命令和键盘 Delete 键调用
  同一个删除动作。
- 删除只调用 macOS 系统废纸篓，不执行永久删除。
- 删除成功后从当前会话移除该项目，并选择原位置附近的项目：
  优先选择原来的下一项；删除最后一项时选择前一项。
- 删除失败时显示本地化错误，当前图片与列表保持不变。
- 没有当前图片时禁用删除命令。

## 4. 直接框选与 `⌘K`

- 用户点击 `Crop` 工具栏按钮或右键菜单的“裁剪”后进入框选模式。
- 框选模式不弹出独立裁剪面板。
- 首次在图片内部按下并拖动时，从按下点到当前点生成新的自由比例裁剪框。
- 已生成的裁剪框可通过边缘和角点调整，也可从内部拖动。
- 普通浏览模式继续保留拖动平移，不让框选操作抢占现有手势。
- 框选模式下按 `Esc` 恢复进入裁剪前的配方并退出。
- 框选模式下按 `⌘K` 立即把当前框选区域覆盖保存到原文件，不弹出另存为
  面板，也不再弹出覆盖确认。
- 覆盖沿用原文件格式；JPEG 和 HEIC 使用质量 `0.9`，并保留可安全保留的
  元数据。
- 只允许覆盖 JPEG、PNG、TIFF 和 HEIC/HEIF。其他源格式显示“不支持覆盖”
  错误并保持框选模式，绝不改变扩展名或偷偷转换格式。
- 覆盖继续使用同目录临时文件、重新解码验证和原子替换。成功后重新加载
  当前文件并退出框选；失败后保留原文件与当前框选。
- `⌘K` 是“裁剪并覆盖”的默认快捷键，不再作为“进入裁剪”的快捷键。

## 5. 右键菜单

右键菜单采用 Picview 的主要分组顺序，但只显示 Imageview 已有且能正确
工作的命令，不显示灰色占位项。

菜单顺序如下：

1. 识别文字
2. 分隔线
3. 实际尺寸
4. 适应窗口
5. 分隔线
6. 排序
   - 名称
   - 扩展名
   - 创建日期
   - 修改日期
   - Finder 顺序
   - 随机
   - Finder 标签
7. 图像处理
   - 左旋
   - 右旋
   - 水平翻转
   - 垂直翻转
   - 裁剪
8. Finder 标签
   - 无标签
   - 灰、绿、紫、蓝、黄、红、橙
9. 分隔线
10. 钉在桌面
11. 在 Finder 中显示
12. 在默认应用中打开
13. 分隔线
14. 复制
15. 删除

菜单动作复用现有窗口命令。没有当前图片时，依赖当前图片的项目禁用。
当前排序和 Finder 标签用勾选状态表示。Picview 中当前版本未支持的自动
OCR、缩放锁定、额外窗口模式、筛选和“在其他应用中打开”不出现在菜单中。

## 6. 应用图标

- 项目根目录的 `Imageview.icns` 是本地应用的正式图标资源。
- 构建脚本把它复制到
  `Imageview.app/Contents/Resources/Imageview.icns`。
- `Info.plist` 通过 `CFBundleIconFile` 指向 `Imageview.icns`。
- 冒烟测试必须检查图标文件存在且 `Info.plist` 的图标声明正确。

## 7. 本地化

新增的工具栏、菜单、错误和裁剪提示同时提供英文与简体中文。
不新增繁体中文资源。

## 8. 验证

- 单元测试覆盖 Delete 默认快捷键为无修饰键的 Delete，以及裁剪默认快捷键
  为 `⌘K`。
- 单元测试覆盖删除当前项目后选择相邻项目的索引行为。
- 现有裁剪导出测试继续证明覆盖采用可重新解码的原子替换。
- UI 测试更新为直接框选/`⌘K` 工作流，并验证三个已移除按钮不存在、
  Delete 按钮存在。
- 构建后验证 `x86_64` 与 `arm64`、代码签名、本地化资源和应用图标。

## 9. 非目标

- 不在本次删除 Pin、Pin Clipboard 或主体提取的底层实现。
- 不补齐 Picview 右键菜单中 Imageview 尚未支持的命令。
- 不增加永久删除。
- 不改变 macOS 12 最低系统要求、Bundle Identifier 或本地交付方式。
